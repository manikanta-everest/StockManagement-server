# StockManagement-server


## About
This is a application for Sock management APIs and it is built with Node.js, Express, and firebase to perform CRUD operations on Products API.

## Tech Stack
- Node.js and Express
- Typescript
- Firebase

## Requirements
 ```
 Express
 Node.js
 Firebase
 ```

## Installation
```
npm install
```

## Build
```
npm build
```

## Start the server
```
npm start
```
